# 成败经验库（lessons）与合规裁剪卡

> 来源：2026-10 网教盟政企众测多轮真实复盘（furongedu work/zhaopin/nuhc/frjsfz）。
> 每轮任务复盘后按文末格式回写新条目。调度 skill 前扫一遍本文件的「调度纪律」部分。

## 一、调度纪律（skill 何时加载、何时裁剪）

1. **到达即加载**（最欠账的教训）：进入 P3 验证某类型假设时，必须真实调用对应 skill 系列。
   两轮复盘实测 0 次 skill 调用，其中两次"该用没用"直接造成断点：
   - `component-vuln-intel` 没查 → SmartAdmin CVE-2026-88619 停在"存疑"，版本适用性与 job 端点映射全靠手工；
   - `secknowledge-skill` 没查 → 教育系统账号命名盲点，只测了 `admin` 一个用户名（乌云案例库里有同类系统的默认账号模式）。
2. **场景外不加载**：P1/P2 阶段不加载攻击类 skill。没进验证环节就别装样子调用——
   这不是省 token，是防流程污染（攻击类 skill 的默认流程会把侦察阶段带偏）。
3. **冲突裁剪留痕**（取可用部分）：skill 内置流程与项目红线冲突时不执行冲突步骤，但必须记录
   「skill 名 + 哪一条 + 为何不执行 + 等价替代」。实测案例：
   - `api-agent` 强制其 scripts/http_test.py 直连发包 → 与"仅经 VPN 代理"冲突 → 不执行该工具条款，
     用自建限速代理抓取器等价实现，其证据规范（真实交互/反幻觉/对照证据）全盘采纳；
   - `hunt-api-misconfig` 的 CORS 节 → 本机规则 CORS 永久不挖 → 跳过该节。
4. **skill 增量价值是实测存在的**：`hunt-api-misconfig` 的 NSwag 节 + `api-recon-and-docs` 的文档变体清单，
   把文档面探测从 4 个路径扩到 17 个；`api-security-testing` 的影子 API/方法混淆补了空白。别凭感觉判"没用"。
5. **零加载也可以是正确决策**（2026-10 审计后修正）：死目标/无凭据/纯静态阶段，攻击类 skill 加载了也只能空转。
   此时应写 `ROUTE: pick=none miss=<理由>` 留痕，而不是为了"看起来勤奋"硬调——但"没写理由"仍算欠账。

## 二、众测/SRC 合规裁剪卡（加载任何攻击类 skill 时一并过）

- 限速：单目标 ≤2 req/s、并发 ≤2；代理强制（项目指定出口），skill 脚本默认直连一律改写。
- 取样：危害证明取样 ≤3；禁拖库/全量分页/导出/批量枚举。
- 禁实爆：弱口令 ≤10 组小字典；限速缺失只定性不实爆；CORS 不挖；子域接管只记指纹。
- 禁持久化/反取证/C2/内网横移（红队场景按 ROE 另议）。
- 登录墙：打通或证伪就停；繁琐验证/别人的 SSO/同皮壳不耗——**看见登录页不是换资产的理由**。
- 会话：禁调登出/注销/吊销接口（保持用户给的会话有效）；写越权先添加→删自己的→不动别人的。
- POC 审读：外部 POC 一律先逐行人工审读，只取请求逻辑改写为最小验证请求，不直接执行第三方脚本。

## 三、高价值打法（实测产出过增量的）

1. **FOFA 四语法**（domain=/host=/icon_hash=/body=）：同主域新面（hrm/bbt:8801）是被动情报最大增量；
   `body="特征串"` 确认自研无外部同款部署。
2. **JS 语料→API 地图流水线**：全量落盘 JS → 11 类敏感情报正则 → 端点提取去重 → 三档分类
   （可实际调用·取样≤3 / 仅探活记录 / 禁止调用）。懒加载 chunk 映射别丢，空壳视图背后的 chunk 才是货。
3. **假设队列状态机**：每条线索→编号假设→状态推进（证实/证伪/受阻/续跑），8 条证伪+2 条止损也是可信交付。
4. **通道判定实验组**：目标"下线"结论需三证据链（四组合探活复测 + 证书史对比 + 业务节奏旁证），
   排除过程本身是工作量主体，不许单点判定。
5. **自定义密码学攻击范式**（nuhc H4b 完整成功）：结构发现（跨密文两两 XOR）→ 成对不变量 →
   受控语料（同参/同秒/UA 阶梯）→ 字母表求交（每位候选=∩{c⊕h}）→ 共识复原（多数票）→ 语义判定。
   全程离线零密钥接触；结论按"可证明/不可证明"两栏定提交性。
6. **升链留白**：差一张样例/一个凭据的发现，写成"人工闭环复现流程"（逐步操作+判定点+定级引用），
   留给持样例者执行——比烂在队列里强。
7. **404 双基线过滤**：先取目标 404 基线（含随机路径的响应形状），再判定路径命中；IIS shortname、
   /trace.axd、/upload/ 禁列目录这类"存在性证明"单独归类。

## 四、环境与工程坑（每轮开工 checklist 过一遍）

- 后台长任务（run_in_background）会被挂起：实测 wscan 卡死 43 分钟 → **长任务一律前台分块（≤10 分钟/块）**。
- 中文路径：heredoc 传参不稳定 → 脚本内用绝对路径落盘。
- 多会话共享目录会被清场 → 每线程独立目录 + 交付物即时落盘。
- 限速经济学：6-10s/发时，4.6k 词字典=5 小时纯等待 → 改精选定向子集（W1-W5 ~360 词已扫穿静态站）。
- 自建 MCP 判据：能用 Bash+Python 等价实现的不强求 MCP；高频复用（限速探测/favicon mmh3）才值得封装。
- pip 代理链先修好（proxy 7897 或换镜像），密码学库（gmssl 等）开工时装好备对拍。

## 五、知识库垂直沉淀（命中过一次就该写下来）

- 指纹→CVE 映射专篇（如 SmartAdmin .NET/Java 双版本）；
- 行业账号命名模式（教育/政务系统常见 jyj/admin888 类）；
- 业务季节性画像（招聘系统=3-8 月上下线，窗口外是"停机"不是"漏洞不存在"）；
- 同类系统历史案例链接（乌云/先知编号直接入档，下轮同款系统秒查）。

## 七、2026-10 能力面大修（541 → 278）与质量分层

### 7.1 变更事实
- 全量内容审计 541 个技能（43.2MB）：**保留 151 可见 + 127 隐藏，归档 263**。
- `route-table.md` 重写为 103 行质量加权表；`quality-index.md` 记录 151 个 V 项的 Q 分与标记。
- 旧表 301 个引用名中 **110 个已失效**（归档/改名）——这正是"路由静默失败"的根源，已清零。

### 7.2 五条硬教训（写进调度动作）
1. **质量 ≠ 可用性**：`identity-provider-recon`(Q5)、`osint-methodology`(Q5)、79 个 `offensive-*`(Q4)
   全部是 **H（隐藏）**，模型不能自动加载。路由到 H 必须记 `ROUTE-MISS: hidden` 并降级，
   或请用户 `/name` 注入。**别把"技能存在"当成"能力可用"。**
2. **Q2 只当入口**：`api-sec`/`auth-sec`/`injection-checking`/`file-access-vuln`/`business-logic-vuln`
   都是 2KB 级路由器，没有方法论。用它们定顺序可以，照着它们做不行。
3. **手册冒充能力（TOOLREQ）**：91 个技能要求本机不存在的脚本/私有 MCP/硬件
   （`api-agent` 要 `http_test.py`、`probe` 要 Nexus、`jtagprobe` 要 J-Link）。
   加载后先验工具存在性，缺则只取方法论，记 `ROUTE-MISS: tool`。
4. **体量即成本（BLOATED）**：30 个 SKILL.md >50KB，最大的 555KB。调用一次就吃掉大半上下文预算；
   这类一律 H 或归档，P3 需要时按需读 reference 分片，不整篇加载。
5. **描述会骗人（MISMATCH）**：13 个描述与正文不符（`web-search` 实为 CLI 导流、
   `security-patterns` 实为 PHP grep、`game-security-research` 实为外挂开发）。
   路由命中不等于内容对得上，加载后扫一眼目录/首节再决定是否照做。

### 7.3 新增的调度动作
- 每回合输出 `GATE` + `ROUTE` 两行；`ROUTE` 必须带 `Qx·V/H` 与 `miss`。
- 选型顺序：V 优先 → Q 降序 → 场景契合 → 数量上限（入口 1、专项 3）。
- 止损线：P1 单 host 15 分钟/3 证据；P3 无凭据 >70% 停；单假设 3 次同结果即收口。
- P2 队列新增必填「前置条件」列——把"卡在一个账号"结构化暴露出来。
